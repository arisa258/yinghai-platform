> 大学生新文科实践创新大赛（经管法组）参赛项目「映海御安阁：中国电影海外舆情与文化安全研判平台构建」的**可上线演示版**。
>
> 纯静态网页（零依赖、零构建），可本地双击打开，也可免费部署到 GitHub Pages 供评委网上访问。**成本 0 元。**

## 平台功能（6 个模块）

| 模块 | 地址 | 内容 |

## 自动报告

在「研判中心」搜索并分析某部影片后，页面会自动生成该影片的**海外舆情深度分析（参考报告）**，并可直接下载 **HTML 打印版 / Word / Markdown** 三种文件，用于内部参考或随项目材料提交。报告为独立成篇的分析参考，不涉密、不绑定特定体系；未配置 API Key 时仍可用本地组装版完整生成，配置后还可一键「AI 深度润色」。

## 研判检索机制

平台采用「**先匹配影片、再中外双名检索**」的机制：搜索时先用中文维基/iTunes 自动匹配实际影片，确认片名、**外文名**与**中国大陆上线时间**，再以国内中文源（Google News·Bing）为主体、外文名检索国际源（英文 Google News + 海外影视媒体）为补充；报告与研判页的时间跨度按「**作品上线时间 至 今天**」计算。

## 采集真实数据（可选，让平台「联网」）

平台演示默认用智库报告数据 + 样例。想接入真实采集：

1. 安装依赖：`pip install requests`
2. 运行：`python collector.py`
3. 脚本会抓取豆瓣电影等公开可直连源，写入 `data/collect.json`，平台自动加载
4. 海外源（Guardian 等）国内网络常受限，抓取失败会自动用样例兜底，不影响演示

> 说明：完整实时联网需要后端服务器（要花钱）；本方案用「本地预采集 + 免费静态托管」实现 0 成本可上线的独立平台，演示时仍能展示真实采集数据。

## 部署上线（GitHub Pages，免费，别人能网上访问）

> 前提：注册免费 GitHub 账号（github.com → Sign up）。

1. **新建仓库**：点右上角 `+` → `New repository`，名填 `yinghai-platform`，选 Public，点 Create
2. **上传文件**：`Add file` → `Upload files`，把 `D:\yinghai-platform` 里所有东西整体拖入，Commit changes
3. **开启 Pages**：`Settings` → `Pages` → Source 选 `Deploy from a branch` → Branch 选 `main` / `(root)` → Save
4. **等待上线**：1–2 分钟后出现 `https://你的用户名.github.io/yinghai-platform/` —— 这就是给评委的正式网址
5. **以后更新**：改完文件重新上传覆盖同名文件 → Commit → 刷新网页（`Ctrl+F5`）

## 常见问题

- **本地双击后「数据采集」页显示演示样例**：正常，说明没运行采集脚本或当前网络抓不到海外源，不影响演示。
- **改完网页没更新**：浏览器按 `Ctrl+F5` 强制刷新。
- **GitHub 上线后 404**：检查文件是否在仓库根目录、Pages 分支是否选对（见部署步骤 2、3）。
- **文件名规范**：所有文件/图片用英文小写，GitHub 服务器区分大小写。
